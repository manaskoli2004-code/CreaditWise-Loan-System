# CreditWise Loan Approval Prediction System

Developed a Machine Learning-based Loan Approval Prediction System using Supervised Learning to predict whether a loan application should be Approved or Rejected based on customer information.

The project aims to automate the loan approval process, reduce manual verification time, minimize biased decisions, and help financial institutions make faster and more accurate lending decisions.

# Objectives
- Analyze historical loan application data.
- Perform data preprocessing and exploratory data analysis (EDA).
- Apply supervised machine learning algorithms for loan approval prediction.
- Evaluate model performance using appropriate classification metrics.
- Predict loan approval status based on applicant details.

# Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Jupyter Notebook

**Project Type:** Machine Learning | Supervised Learning | Classification
